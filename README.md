# Mind Your Five Ps: Which Founder Are You?

A static, mobile-friendly marketing quiz built from the submitted `mind-your-five-ps-materials.xlsx` workbook. It presents 20 real-world business challenges with four choices each, reveals the answer key and historical outcomes at the end, awards 5 points per correct answer, and matches the strongest Five P category to a founder.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. Keep the `assets` directory alongside the HTML, JavaScript, and CSS files.

## Publish

The site is deployed from the `main` branch root using GitHub Pages.
