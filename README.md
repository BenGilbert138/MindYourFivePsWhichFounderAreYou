# Mind Your Five Ps: Which Founder Are You?

A static, mobile-friendly marketing quiz built from the submitted `mind-your-five-ps-materials.xlsx` workbook. It presents 20 real-world business challenges with four choices each, awards 5 points per correct answer, and matches the strongest Five P category to a founder.

Challenges are ordered by their listed historical date; decade-only dates are ordered by the start of the decade. After each response, the game immediately shows the correct answer and the workbook's historical context, with a full answer key also available at the end. Founder portraits appear as category guides and on the final match cards.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. Keep the `assets` directory alongside the HTML, JavaScript, and CSS files.

## Publish

The site is deployed from the `main` branch root using GitHub Pages.
